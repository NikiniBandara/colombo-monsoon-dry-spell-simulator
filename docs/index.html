About / How to use

Colombo can experience runs of days with little rainfall. This tool explores how likely a selected dry spell is under historical seasonal patterns. It is a historical-risk scenario simulator, not an operational weather forecasting service.

Model and data

A first-order seasonal Markov chain chooses each day's Wet (0) or Dry (1) state from the previous day's state and the season of the new day. A dry day has less than 1 mm of rainfall. Transition probabilities were fitted to 1991–2018 data; the notebook evaluates the model on 2019–2025. Monte Carlo simulation repeats this process many times and counts dry spells inside the selected date window.

Data credit: the project's Colombo daily rainfall CSV covers 1991–2025 and identifies a 7.0° N, 80.0° E grid point in the Asia/Colombo time zone. The project attributes its historical rainfall data to Open-Meteo ERA5 reanalysis, produced by Copernicus Climate Change Service / ECMWF.

Settings and controls

  • Start date and duration choose the simulation window. The season is chosen separately for each day.
  • Simulations sets how many independent scenarios to run. More runs give a steadier probability estimate.
  • Minimum dry spell is the number of consecutive dry days counted as a risk event.
  • Previous day's state sets Wet or Dry immediately before the first simulated day.
  • Random seed makes repeated browser runs with identical settings reproducible.

Select Start for a new run. Pause stops after the current batch; Resume continues the same run and random sequence. Reset cancels the run and restores the reference settings. Load and run reference runs the notebook comparison.

Reading the results

The risk is the fraction of scenarios with a spell meeting your minimum. The other two values are average counts of dry days and average longest spell length. Blue means Wet in the scenario chart and below threshold in the histogram; amber means Dry or at/above threshold. The charts update during a run.

The 95% Wilson interval describes Monte Carlo sampling uncertainty in the estimated risk. It does not include uncertainty in the fitted model, rainfall data or future climate. The model does not simulate rainfall amounts, and it only remembers the previous day's wet/dry state.
